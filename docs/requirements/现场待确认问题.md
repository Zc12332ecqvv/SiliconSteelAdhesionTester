# 现场待确认问题

以下信息无法从《PC交互表》和现有程序资料中可靠推断，投产前必须由电气、视觉、LIMS或设备供应商确认。

## 1. PLC通讯

1. S7-1200是否确定采用S7通讯协议但监听端口为502，而不是标准102？
2. Rack、Slot是否确定为`0/1`？
3. 是否已在PLC中允许PUT/GET访问，并关闭相关DB的优化块访问？
4. 请逐项确认下列地址，尤其是第一次拍照与S4返回位：
   - S2第一次拍照允许 `DB4120.DBX579.0`
   - S2第一次拍照完成 `DB4120.DBX577.0`
   - S2第二次拍照允许/完成/OK/NG `578.0 / 576.0 / 576.1 / 576.2`
   - S4拍照允许/完成/OK/NG `1110.0 / 1108.0 / 1108.1 / 1108.2`
5. 第一次拍照没有NG位。相机超时或失败时，PLC应等待、重试、报警还是有其他故障地址？
6. PLC允许位最长保持多久？PC应答超时由谁负责报警和复位？

## 2. SR-1000二维码读取器

1. 现场是一台还是两台SR-1000？取向与无取向的实际IP和端口分别是什么？
2. PC是TCP客户端连接读取器，还是读取器作为TCP客户端主动连接PC？
3. 触发读取命令、停止命令、命令结束符分别是什么？
4. 返回字符编码、正常二维码报文样例、读取失败/超时/多码时的报文样例各提供至少3条。
5. SR-1000是否已配置为仅输出二维码结果，还是还会输出命令回显、状态码、质量信息？
6. 二维码最小/最大长度、重复读取间隔和允许字符范围是什么？

## 3. 相机与视觉软件

1. 相机品牌、型号、数量、IP、连接方式及SDK/GenICam版本。
2. 是PC直接调用相机SDK，还是调用独立视觉软件/HTTP接口？
3. 如果由视觉软件保存图片，请确认落图目录、命名规则及“文件写完”的标志。
4. 第一次和第二次拍照是否使用同一台相机、同一曝光参数、同一ROI？
5. 图片分辨率、像素格式、曝光、增益、光源控制和触发模式。
6. 是否允许多件样品同时在流水线上？如果允许，PLC如何向PC提供样品序号以防图片与二维码错配？

## 4. 判定规则

1. 取向样品ROI和压弯前后图像对齐方法。
2. 无取向胶带ROI、背景颜色和胶带标准放置方式。
3. 合格依据是脱落面积百分比、颗粒数、最大颗粒尺寸还是A/B/C等级组合？
4. 取向、无取向的阈值是否相同？当前临时值均为3%。
5. 提供合格、临界、不合格标准样品图片各10组以上用于标定。
6. 视觉算法失败、图片模糊、曝光异常、ROI缺失时是否一律返回NG？

## 5. 任务与LIMS

1. 二维码内容字段定义及脱敏样例5至10条。
2. 二维码是否只用于追溯，还是必须查询LIMS验证任务有效性？
3. LIMS接口协议、URL、认证方式、请求/响应JSON、超时和重试要求。
4. 一件样品、一个任务、一个料盘和一个二维码之间的对应关系。
5. 离线生产是否允许？断网数据补传的最大期限和人工处理方式。
